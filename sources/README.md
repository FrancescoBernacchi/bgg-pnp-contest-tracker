# Fonti

Registro delle fonti BGG e delle evidenze riutilizzabili. Ogni record deve distinguere URL, tipo di pagina, identificativo BGG quando disponibile, data di osservazione e data dell'ultima verifica.

BoardGameGeek è l'unica fonte esterna autorizzata nella fase corrente. L'ordine di preferenza è: thread o post ufficiale dell'organizzatore, GeekList ufficiale, Design Contest Hub e metadati pubblici dei thread WIP. Risultati ufficiali, conteggi ricavati e inferenze devono restare esplicitamente distinti.

`MONITORING_CALENDAR.md` è il taccuino operativo: governa quando tornare sulle fonti, ma non sostituisce la cronologia nel database. La data di aggiornamento del taccuino non equivale a una nuova verifica BGG se il file è stato modificato soltanto per manutenzione documentale.
