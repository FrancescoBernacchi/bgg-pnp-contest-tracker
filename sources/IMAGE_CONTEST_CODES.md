# Registro sigle contest per immagini

Adottato in TSK-0065, 2026-10-05. Sigle brevi, stabili e univoche per serie contest; anno a quattro cifre nel nome immagine. Conservare contest ID e nome completo nel manifest. Verificare collisioni prima di assegnare una sigla e registrare data/fonte del mapping. Non rinominare retroattivamente file senza incremento esplicito.

Nessuna sigla operativa ancora assegnata. `9C` negli esempi del brainstorming è illustrativa.
